# 02 - Python 内存优化与生成器 (Generators)

## 💡 核心概念
*   **迭代器 (Iterator) vs 列表 (List)**：列表会将所有数据一次性加载到内存中；而迭代器只在需要时生成下一个值。
*   **生成器 (Generator)**：一种特殊的迭代器，通过 `yield` 关键字返回值，而不是 `return`。它的核心优势是**延迟计算 (Lazy Evaluation)**。

## 🚀 场景化选型 (云/数据工程场景)
*   **场景 1：处理海量日志/CSV 文件**
    *   千万不要使用 `file.readlines()`（一次性读入内存）。
    *   **最佳实践**：直接遍历文件对象 `for line in file:`，或者编写带有 `yield` 的生成器函数按块处理。
*   **场景 2：数据库批量导出**
    *   千万不要用 `cursor.fetchall()` 抓取数百万条记录。
    *   **最佳实践**：使用 `cursor.fetchmany(chunk_size)` 配合生成器，按批次将数据流式写入 S3 或其他存储。

## 🎯 常见面试题对答技巧
**Q: 如何在只有 8GB 内存的服务器上处理 50GB 的文件？**
**A:** 绝不能将文件一次性读入内存。我会使用 Python 的生成器（Generator）按行或者按块（Chunk）读取文件。比如使用 Pandas 时，可以加上 `chunksize` 参数；如果是纯 Python 操作，我会定义一个包含 `yield` 的函数，每次只返回几千行数据进行处理，处理完即释放内存，保证内存占用始终在一个极低的常量级别。
